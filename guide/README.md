# 离线攻略素材说明

`guide.json` 是为 Mac 版重新编写的离线逐步解法，按两部作品的十话及各话的调查、共同推理、法庭阶段组织，共 336 条编号操作。它不包含网页、图片、视频、奖杯清单或外部跳转；游戏运行时只读取 App 内的 JSON，不请求网络。

流程与关键选择交叉核对了 [第一部 GameFAQs 流程](https://gamefaqs.gamespot.com/switch/318976-the-great-ace-attorney-chronicles/faqs/73514)、[第二部 BAI Gaming 流程](https://bai-gaming.com/guides/great-ace-attorney-2-walkthrough/)、[StrategyWiki 第一部目录](https://strategywiki.org/wiki/The_Great_Ace_Attorney%3A_Adventures/Table_of_Contents)、[第二部目录](https://strategywiki.org/wiki/The_Great_Ace_Attorney_2%3A_Resolve/Table_of_Contents)和[中文流程目录](https://www.bilibili.com/read/mobile-readlist/rl17559)。正文为本项目重新组织、撰写的操作提示，没有复制攻略正文或图片。步骤只列会推进剧情的调查、追问、举证和选择；普通对话与过场可自行推进。证物译名可能随汉化版本变化，必要时以游戏内图标和描述辨认。全部章节尚未实机通关核对。
