- 使用日版 1.0.0 的 `main` Build ID 建立独立配置，沿用国际版已经验证的 `subsdk0`、`sdk`、内存、纹理上传与深度设置；配置见 `profiles/0100D7F00FB1A000/game.tsv`。

- 画质与鼠标触控联动调查（2026-10-29）：当前保存设置为掌机模式，日志的 `WindowCrop` 是 1280×720；电视模式是 1920×1080。Mac 前端无论何种模式都会把左键转换为归一化触点，但宿主 `dm/host/hle_hid.c` 在电视模式返回空触点。隔离修改宿主后，电视模式的 `DM_TOUCH_LOG` 已记录到 `main+0x716b4c` 读取的触点；同一“自动存档说明”页在掌机模式点“了解”会进入标题动画，在电视模式仍停留原页。游戏启动时从 `main+0x7fe114` 与 `main+0x727d78` 两次查询主机模式。只改第一处查询会先裁 720p 再切回 1080p，但点击仍无效；掌机模式强制 Boost 仍只裁 720p。隔离二进制试验跳过 `main+0x717a88` 的一个触控标志判断，电视模式点击仍无效。上述试验均使用隔离存档与模块副本，已从源码撤回，项目 App 和安装版均未改动。后续需要进一步追踪游戏内触点使用处并做版本限定补丁，不能只移除宿主拦截。
- GitHub 方案核对：`nxnative` 的《脑锻炼学院》配置证明有游戏能在掌机模式加 Boost 后绘制 1920×1080（`https://github.com/seedds/nxnative/blob/main/dm/games/0100620012D6E000/README.md`），但本作的上述隔离测试已排除直接套用。ReverseNX-RT 的自定义掌机分辨率依赖游戏调用 `GetDefaultDisplayResolution`（`https://github.com/masagrator/ReverseNX-RT`）；本作日版 `main.patched.bin` 的导入符号有 `GetOperationMode` / `GetPerformanceMode`，没有该分辨率接口，因此该路径不能直接套用。`dgs_hackfix` 能解除 PC 版分辨率列表限制（`https://github.com/AdmiralCurtiss/dgs_hackfix`），但它针对 Windows `TGAAC.exe` 的 DINPUT8 注入，不适用于 Switch ARM64 程序。未在这些项目中找到本作日版 1.0.0 可直接应用的“1080p + 触控”补丁。技术方向是给本作 `main` 按 Build ID 制作专用补丁，分别改手持模式下的渲染尺寸、输入模式判断和必要的坐标缩放；隔离截图和通关场景验证后才能打包。
- 高清触控实现（2026-10-29）：`main+0x727c78` 将画面尺寸复制到当前渲染对象，`main+0x728104` 将该尺寸传给 `nvnWindowSetCrop`。日版 1.0.0 专用 `profiles/0100D7F00FB1A000/patches.py` 在前一处跳转至 text 与 rodata 间的 16 字节空隙，设尺寸为 1920×1080 后返回；`patch_nso.py` 用 Build ID 和原字节断言再应用。宿主 `DM_TOUCH_1080=1` 把归一化鼠标触点映射到 1920×1080，同时继续报告掌机输入模式。隔离运行日志记录 `WindowCrop 0,0 1920x1080` 和触点 `(960,734)`；在自动存档提示点“了解”后，`frame780.png` 显示完整的 1080p 标题房间。未启用 `DM_TOUCH_1080` 时，画面虽为 1080p，但相同点击无法通过提示，证明触点坐标缩放是必要的。重跑 `patch_nso.py` 生成文件的 SHA-256 与手工隔离验证文件完全相同。此处只验证了启动流程和画面，后续仍需在菜单、剧情、调查和法庭验证触控与渲染细节。
- 隔离交互扩展：鼠标点击标题“请按下按钮”成功进入主菜单；点击“继续游戏”打开存档确认；点击“是”进入加载画面，游戏继续运行到至少第 2400 帧，无崩溃。`main.cuts.tsv` 记录两处专用补丁；项目 App 和 `~/Applications` 安装版均换入同一宿主与 `main.patched.bin`，写入 `DM_TOUCH_1080=1`，并通过 `codesign --verify --deep --strict`。完整剧情、调查、法庭的触控仍待人工游玩检查。
