# 第一阶段：输入与日版差异

初次记录日期：2026-10-27；2026-10-28 更新密钥文件状态。以下为文件名、通用文件类型识别和目录结构的**静态观察**，未验证 XCI 内部元数据或运行效果。

## 本地观察

- 标红本体：`The Great Ace Attorney Chronicles [Japan] [0100D7F00FB1A000].xci`，4,615,783,936 字节。`file` 识别为 Nintendo Switch XCI；Title ID 与版本目前仅来自文件名，不能据此确认内部程序构建。
- 标红汉化目录：`0100D7F00FB1A000/romfs/nativeNXx64/`，137 个文件，总计 236,817,070 字节。扩展名分布：58 个 `.gmd`、34 个 `.tex`、30 个 `.arc`、15 个 `.sdl`。没有观察到 `exefs` 文件。逐文件相对路径、大小和 SHA-256 见 [patch-manifest.tsv](patch-manifest.tsv)。
- 同目录的 `SWITCH大逆转裁判编年史汉化补丁.rar` 列出同名 Title ID 的 `romfs` 路径；尚未逐文件比较 RAR 与解压目录的内容。
- 另有文件名带 `[CN1.3]` 的整合版 XCI，4,244,941,824 字节，文件名中的 ID 不同。`file` 识别为 XCI，偏移 `0x100` 的容器标记是 `HEAD`。这只能确认它是 XCI 容器，**不能证明其中 NCA 内容已解密**；不作为干净基线，内部身份也未核对。
- 用户已在上述游戏目录的 `ProdKeys.NET-v22.5.0/` 子目录放置 `prod.keys`。只读格式检查发现 231 个条目、无格式错误或重复名称，包含常见 NCA 解密所需的密钥类别；**尚未通过解密 XCI 验证密钥值**。检查没有记录或显示密钥值。

## 与现有开源配置的差异

`nxnative` 的已测试配置是国际版 `010036E00FB20000` 本体 1.0.0，记录为 Capcom MT Framework、Switch SDK 10.4.1、NVN 图形，并仅在 Mac 上验证到第一部第一话的部分剧情与法庭。该配置不能直接证明日版同一程序构建或汉化可用。[本作配置记录](https://github.com/seedds/nxnative/blob/main/dm/games/010036E00FB20000/README.md)

另一翻译项目明确区分国际版 `010036E00FB20000` 与日版 `0100D7F00FB1A000` 的补丁目录。这支持两个 ID 是不同地区发行，但不证明两版程序二进制相同。[DGS-FR Switch 说明](https://github.com/AAI-fr/DGS-FR#nintendo-switch)

## 后续验证顺序

1. 准备本地 XCI 提取工具，使用用户在项目外提供的密钥尝试读取日版本体，再从提取出的完整 `ExeFS`、`RomFS` 和控制数据中核对程序模块名、构建 ID、内部 Title ID 与版本。提取输出放在 Git 忽略的本地数据目录，不改动原始 XCI。
2. 对照 `nxnative` 国际版配置的模块、SDK、资源布局和专用修复，形成日版差异表。不同构建 ID 不套用国际版的程序地址补丁。
3. 以未汉化日版建立启动、标题、影片、声音、输入和存档基线。
4. 在不修改原始 XCI 的前提下，将汉化 `romfs` 覆盖层接入构建流程；重点验证中文字体、文本换行、图片、字幕以及两部作品的章节。
5. 扩大验证到完整流程；现有公开记录只覆盖开头，不代表通关验证。
