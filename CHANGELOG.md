# Changelog

## Initial experimental source release — 2026-11-01

- Japanese Switch base 1.0.0 profile for Apple silicon Mac, based on nxnative.
- Separate original Japanese/English and optional Chinese-overlay build paths, with independent app preferences and save directories.
- English and Simplified Chinese launcher/menu support; English defaults for the original build.
- Resolution selection, experimental 60 FPS/EDR configuration, mouse touch, keyboard bindings, and controller glyph support.
- Chinese and English documentation, MIT license, and retained third-party notices.
- Ten build/localization tests and three native overlay regression tests passed locally. The English local smoke test covered startup, title/menus, opening subtitles, and the beginning of Episode 1; full playthroughs and long-session stability remain unverified.

This repository contains tools, source patches, configuration, and documentation. No game executables/assets, Chinese translation resources, keys, saves, App bundles, or DMG installers are included. See the README and license notices for scope and limitations.
